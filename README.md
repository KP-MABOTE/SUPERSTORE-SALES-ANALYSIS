# SUPERSTORE-SALES-ANALYSIS
Retail sales analysis and dashboard, NexAfrica Data Analysis Internship

## About This Project
This project analyzes the Superstore Sales dataset to help management understand business performance across products, customers,
regions, and time. Identifying trends, uncovering problems, and supporting data-driven
decisions. The project runs over 5 weeks, from data cleaning through to a full interactive
dashboard.

## Dataset
The Superstore Sales dataset — 9,994 order line items across 21 columns, covering orders
placed between January 2014 and December 2017.

## Tools
- Excel (data cleaning, KPI calculations, PivotTables)
- Power BI (interactive dashboard)
